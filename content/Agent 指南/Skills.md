# Skills

## 一瞥

希望 Agent 能够一次完成多个任务,如

+ 阅读论文
+ 复现代码
+ 日志分析

一种方法是将每次都输入大量规则,一种方法是将每类任务的工作流程包装成 Skill

## 结构

一个常见的 Skills 一般拥有结构

paper-reading/
├── SKILL.md
├── references/
│   ├── paper-review-guide.md
│   └── model-architecture.md
├── scripts/
│   └── extract_pdf.py
└── assets/
    └── review-template.md

实例

```

---
name: paper-reading
description: 阅读和分析机器学习、机器人学论文。当用户要求解读论文、分析模型架构或梳理训练流程时使用。
---

# 论文阅读技能

## 工作流程

1. 确认论文的研究问题和核心贡献。
2. 分析模型整体架构及各模块的输入输出。
3. 梳理训练数据、损失函数和优化方法。
4. 区分论文明确陈述的内容与自己的推断。
5. 总结实验结果、局限性和可复现性。

## 输出格式

- 研究问题
- 核心思想
- 模型架构
- 训练方法
- 实验结果
- 局限性与改进方向

## 规则

优先依据论文原文，不要编造实验结果。
遇到公式时解释变量含义和张量维度。
```

## 实现

常见实现为**渐进式加载**,先了解技能基本信息,需要时详细读取

1. 注册 Skill
2. 判断是否匹配任务
3. 加载技能说明
4. 执行任务

Skill 不会自动实行,Agent 必须实现**技能发现/加载/执行**机制

Skill 本质上是将 prompt 按照指定规范格式打包的操作,简单来说,也可以不实现 Skill 后端,直接将 skill 当作 prompt 读取,但是如果 Skills 过大,则需要合理的后端读取顺序
