1. Magic 命令

Magic 命令以 % 开头，由 IPython 提供。

%time

执行一次代码并统计运行时间。

%timeit

多次执行代码并统计平均运行时间。

适合比较不同代码的运行效率。

%run

运行 Python 文件。

带参数：

%load

将 Python 文件内容加载到当前 Cell。

也可以加载网络资源：

%save

将当前 Cell 保存为 Python 文件。

%history

查看输入历史。

%rerun

重新执行之前的代码。

%recall

取出之前执行过的代码，但不执行。
